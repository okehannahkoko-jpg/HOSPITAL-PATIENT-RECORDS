# Hospital Patient Records – Excel Capstone Project

## About the Project

This is my Excel capstone project. I worked with records of 1,000 patients admitted to a hospital between 2022 and 2024, and built a dashboard to show how the hospital is doing.

## Tools Used

- Microsoft Excel

## What I Did

- Cleaned the data and added new columns, like year and month of admission, age group, cost per day, BP category and a readmission flag.
- Worked out the key numbers, like total patients, average age, average length of stay, readmission rate and ICU rate.
- Used pivot tables to summarise the data.
- Built pivot charts showing:
  - Admissions by department and patient status
  - Average cost by insurance type
  - Patient status breakdown
  - Monthly admissions
  - Readmission rate by department
  - Average length of stay by diagnosis
  - Doctor workload and readmission rate
- Put the charts together on one dashboard with filters so you can explore the results.

## Result

The dashboard gives a quick picture of the hospital. Most patients were discharged, the average stay was about 5 days, and around 12% of patients came back within 30 days. You can also see which departments are busiest and which diagnoses keep patients in longest.

## What I Learned

This project helped me get better at using pivot charts. I also learned how to put charts together into a dashboard that is easy to understand.
